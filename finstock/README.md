# finstock

Плагин Claude Code для складского и финансового учёта finstock: подключает MCP-сервер агента и скилл с правилами
работы с его ручками и справочником кодов отказа.

## Установка

```
/plugin marketplace add webkoth/claude-code-plugins
/plugin install finstock@webkoth
```

## Настройка

- `FINSTOCK_TOKEN` — токен агента, который выдаёт владелец на экране «Пользователи». Задайте его в окружении до
  запуска Claude Code; в файлах плагина токена нет. Пока переменная не задана, сервер не подключится. Какие ручки
  появятся у агента, решают отметки на токене.
- `FINSTOCK_MCP_URL` — адрес сервера. Нужен только для своей копии finstock; по умолчанию используется боевой.
