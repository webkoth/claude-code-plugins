# Ручки finstock

Построен из реестра ручек (`apps/web/src/agent/tools`), руками не править: `npm run agent:skill -w @finstock/web`. Вход — та же схема, что видит клиент MCP. «Обязательное» — во всех видах документа; какие поля нужны какому виду (`kind`, `type`), говорит описание ручки. Деньги — целые копейки (поля `…_minor`).

## Склад (`sklad`)

### `product_archive` — Архивировать товар

Право `write` (Черновики и справочники) · запись

Переносит товар в архив (archived: true) или возвращает из архива (false).

Вход:
- `id` — обязательное; integer > 0, ≤ 2147483647
- `archived` — обязательное; boolean

### `product_get` — Товар

Право `read` (Чтение) · чтение

Карточка товара по id: артикул, название, штрихкод, группа, себестоимость в копейках и её источник.

Вход:
- `id` — обязательное; integer > 0, ≤ 2147483647

### `product_save` — Сохранить карточку товара

Право `write` (Черновики и справочники) · запись · ключ повтора `idempotency_key`

Создаёт карточку товара или правит существующую (id): article, name, group_name, barcode, description, image_url. Правка заменяет запись целиком: прочитайте её (`product_get`) и пришлите каждое поле; пустое — null. Цену (себестоимость) ручка не принимает и существующую не меняет: цена — ручкой `product_set_cost` с правом `costs`.

Вход:
- `id` — необязательное; integer > 0, ≤ 2147483647
- `article` — обязательное; string длиной не меньше 1
- `name` — обязательное; string длиной не меньше 1
- `group_name` — обязательное; string | null
- `barcode` — обязательное; string | null
- `description` — обязательное; string | null
- `image_url` — обязательное; string | null
- `idempotency_key` — необязательное; string длиной 1–200 — Ключ повтора: повтор вызова с тем же ключом после обрыва связи не заводит вторую запись, а возвращает ответ первого. Ключ уникален в пределах токена. Тот же ключ повторяйте ровно при повторе того же вызова; на новую запись — новый ключ. Тот же ключ с другим входом — отказ idempotency_key_reused.

### `products_list` — Товары

Право `read` (Чтение) · чтение

Каталог товаров по артикулу: артикул, название, штрихкод, себестоимость в копейках и её источник. Архивные — по флагу. В rows — не больше limit (200), в total — сколько всего.

Вход:
- `include_archived` — необязательное; boolean, по умолчанию false
- `limit` — необязательное; integer ≥ 1, ≤ 1000, по умолчанию 200

### `products_set_group` — Назначить группу товарам

Право `write` (Черновики и справочники) · запись

Ставит группу (group_name; null — снять) списку товаров, до 1000 id без повторов. Новая группа создаётся на месте.

Вход:
- `ids` — обязательное; массив из integer > 0, ≤ 2147483647 (от 1 до 1000)
- `group_name` — обязательное; string | null

### `stock_document_check_post` — Проверить проведение документа склада

Право `read` (Чтение) · чтение

Проверка проведения складского документа без записи: те же правила, что у stock_document_post, но ничего не пишется. Отвечает warnings (предупреждения, которые проведение потребует принять в accept_warnings), movements (сдвиг остатка по товару, штук) и cost_updates (цены товаров до и после, в копейках). Отказ правил — те же коды, что у проведения (например negative_stock). Предупреждения проведение сверяет заново: между проверкой и проведением цену могли поменять.

Вход:
- `id` — обязательное; integer > 0, ≤ 2147483647
- `kind` — обязательное; "receipt" | "shipment" | "return" | "writeoff" | "stocktake"

### `stock_document_delete_draft` — Удалить черновик документа склада

Право `write` (Черновики и справочники) · запись · разрушающая

Удаляет черновик документа склада по id и виду. Проведённый документ и документ с движениями не удаляется.

Вход:
- `id` — обязательное; integer > 0, ≤ 2147483647
- `kind` — обязательное; "receipt" | "shipment" | "return" | "writeoff" | "stocktake"

### `stock_document_get` — Складской документ

Право `read` (Чтение) · чтение

Складской документ по id: шапка, строки с товарами, количеством и ценой в копейках, статус проведения. У поступления costEvents — цены, записанные документом: до документа, документа и сейчас, и можно ли вернуть прежнюю (stock_cost_revert); у прочих видов пусто.

Вход:
- `id` — обязательное; integer > 0, ≤ 2147483647

### `stock_document_post` — Провести документ склада

Право `stock_post` (Проведение склада) · запись

Проводит складской документ: пишет движения остатка, поступление — и цену товаров. accept_warnings — какие предупреждения принять; пустой массив — ничего не принято, и проведение с предупреждением отказывает warnings_not_accepted без записи. cost_differs (поступление перезапишет существующую цену товара) принимается только токеном с правом costs, иначе отказ missing_scope. Что изменится — заранее покажет stock_document_check_post.

Вход:
- `id` — обязательное; integer > 0, ≤ 2147483647
- `kind` — обязательное; "receipt" | "shipment" | "return" | "writeoff" | "stocktake"
- `accept_warnings` — обязательное; массив из "cost_differs"

### `stock_document_save_draft` — Сохранить черновик документа склада

Право `write` (Черновики и справочники) · запись · ключ повтора `idempotency_key`

Создаёт черновик документа склада или правит существующий (id). Поля по kind: receipt (поступление) — receipt_kind; shipment (отгрузка) — basis, basis_platform (обязательна при basis marketplace), basis_order_ref, received_minor; return (возврат) — return_of_id; writeoff (списание) — writeoff_reason; stocktake (инвентаризация) — у строк expected_quantity. У всех — doc_at, comment, lines (product_id, quantity, cost_minor). Правка заменяет запись целиком: прочитайте её (`stock_document_get`) и пришлите каждое поле своего вида в snake_case полях этой ручки; пустое — null, поле другого вида или неизвестное — ошибка входа. Деньги — целые копейки. Не проводит документ.

Вход:
- `kind` — обязательное; "receipt" | "shipment" | "return" | "writeoff" | "stocktake"
- `id` — необязательное; integer > 0, ≤ 2147483647
- `doc_at` — обязательное; string (date-time)
- `comment` — обязательное; string | null
- `idempotency_key` — необязательное; string длиной 1–200 — Ключ повтора: повтор вызова с тем же ключом после обрыва связи не заводит вторую запись, а возвращает ответ первого. Ключ уникален в пределах токена. Тот же ключ повторяйте ровно при повторе того же вызова; на новую запись — новый ключ. Тот же ключ с другим входом — отказ idempotency_key_reused.
- `receipt_kind` — необязательное; "new" | "opening" | "found"
- `lines` — обязательное; массив объектов (не больше 1000) | массив объектов (не больше 1000)
  - вариант 1: массив объектов (не больше 1000)
    - `product_id` — обязательное; integer > 0, ≤ 2147483647
    - `quantity` — обязательное; integer ≥ 0
    - `cost_minor` — обязательное; integer ≥ 0 | null
  - вариант 2: массив объектов (не больше 1000)
    - `product_id` — обязательное; integer > 0, ≤ 2147483647
    - `quantity` — обязательное; integer ≥ 0
    - `cost_minor` — обязательное; integer ≥ 0 | null
    - `expected_quantity` — обязательное; integer
- `basis` — необязательное; "marketplace" | "offline" | "kit"
- `basis_platform` — необязательное; "wb" | "ozon" | "ym" | null
- `basis_order_ref` — необязательное; string | null
- `received_minor` — необязательное; integer ≥ 0 | null
- `return_of_id` — необязательное; integer > 0, ≤ 2147483647 | null
- `writeoff_reason` — необязательное; "defect" | "lost" | "gift" | "exhibition" | "other"

### `stock_document_unpost` — Отменить проведение документа склада

Право `stock_post` (Проведение склада) · запись · разрушающая

Отменяет проведение складского документа: гасит его движения остатка обратными, документ снова черновик. Отвечает id, product_count (сколько товаров затронуто) и cost_events (у поступления: цена до документа, цена документа, цена сейчас и можно ли вернуть). Важно: цену отмена не возвращает; что можно откатить — в cost_events, откат — stock_cost_revert (по товару).

Вход:
- `id` — обязательное; integer > 0, ≤ 2147483647
- `kind` — обязательное; "receipt" | "shipment" | "return" | "writeoff" | "stocktake"

### `stock_documents_list` — Складские документы

Право `read` (Чтение) · чтение

Список складских документов одного вида (receipt, shipment, return, writeoff, stocktake) за период, от новых к старым: номер, дата, статус, число строк и штук, сумма в копейках. Самих строк нет — они в stock_document_get. В rows — не больше limit (200), в total — сколько всего.

Вход:
- `kind` — обязательное; "receipt" | "shipment" | "return" | "writeoff" | "stocktake"
- `from` — необязательное; string по шаблону ^\d{4}-\d{2}-\d{2}$
- `to` — необязательное; string по шаблону ^\d{4}-\d{2}-\d{2}$
- `status` — необязательное; "all" | "draft" | "posted", по умолчанию "all"
- `origin` — необязательное; "all" | "auto" | "manual"
- `limit` — необязательное; integer ≥ 1, ≤ 1000, по умолчанию 200

### `stock_movements` — Движения товара

Право `read` (Чтение) · чтение

Журнал движений одного товара по складским документам, от старых к новым: приход и расход штук с датой и id документа. В rows — последние limit (200), в total — сколько всего.

Вход:
- `product_id` — обязательное; integer > 0, ≤ 2147483647
- `limit` — необязательное; integer ≥ 1, ≤ 1000, по умолчанию 200

### `stock_now` — Остатки сейчас

Право `read` (Чтение) · чтение

Остатки своего склада на сейчас по товарам с остатком: штуки, себестоимость и стоимость в копейках, дни на складе — тот же расчёт, что вид «Склад» на «Товарах». В platforms — остаток каждой площадки по штрихкоду из последнего снимка; площадки зеркалят один склад, складывать их нельзя.

Вход: полей нет.

### `money_document_save_draft` — Сохранить черновик денежного документа

- `counterparty_id` — необязательное; integer > 0, ≤ 2147483647 | null
- `channel` — необязательное; "wb" | "ozon" | "ym" | "kit" | "none"
- `purpose` — необязательное; string | null
- `links` — необязательное; массив объектов (не больше 1000)
  - `report_id` — обязательное; integer > 0, ≤ 2147483647
  - `amount_minor` — обязательное; integer > 0
- `offline_shipment_id` — необязательное; integer > 0, ≤ 2147483647 | null
- `expense_item_id` — необязательное; integer > 0, ≤ 2147483647

### `money_document_unpost` — Отменить проведение денежного документа

Право `money_post` (Проведение денег) · запись · разрушающая

Снимает проведение денежного документа: он снова черновик, движение по счёту убирается. Отвечает id. Отказывает negative_balance, если без документа остаток счёта где-то после его даты уходит в минус; not_posted — документ не проведён.

Вход:
- `id` — обязательное; integer > 0, ≤ 2147483647
- `kind` — обязательное; "in" | "out" | "transfer" | "adjustment"

### `money_documents_list` — Денежные документы

Право `read` (Чтение) · чтение

Список денежных документов одного вида (in — поступления, out — платежи, transfer — перемещения, adjustment — корректировки) за период, от новых к старым: номер, дата, счёт, контрагент, сумма в копейках, статус. В rows — не больше limit (200), в total — сколько всего.

Вход:
- `kind` — обязательное; "in" | "out" | "transfer" | "adjustment"
- `from` — необязательное; string по шаблону ^\d{4}-\d{2}-\d{2}$
- `to` — необязательное; string по шаблону ^\d{4}-\d{2}-\d{2}$
- `status` — необязательное; "all" | "draft" | "posted", по умолчанию "all"
- `account_id` — необязательное; integer > 0, ≤ 2147483647
- `expense_item_id` — необязательное; integer > 0, ≤ 2147483647
- `limit` — необязательное; integer ≥ 1, ≤ 1000, по умолчанию 200

### `payment_templates_materialize` — Создать платежи из шаблонов

Право `write` (Черновики и справочники) · запись

Создаёт черновики платежей из действующих шаблонов за месяц (month, ГГГГ-ММ) — как кнопка «Создать платежи». Повтор за тот же месяц черновиков не дублирует: в ответе created — создано, existed — уже было.

Вход:
- `month` — обязательное; string по шаблону ^\d{4}-(0[1-9]|1[0-2])$

### `supplier_advance_link` — Закрыть аванс поступлением

Право `money_post` (Проведение денег) · запись

Закрывает аванс — проведённый платёж по статье «Закупка материалов» (payment_id) — поступлением (receipt_id) на меньший из остатков. Открытые поступления с остатками — в поле advance ответа money_document_get у платежа. Отвечает payment_id, receipt_id и amount_minor — сумму связи в копейках; повтор пересчитывает ту же связь. Отказ — код (payment_not_posted, not_materials, receipt_without_cost и другие).

Вход:
- `payment_id` — обязательное; integer > 0, ≤ 2147483647
- `receipt_id` — обязательное; integer > 0, ≤ 2147483647

### `supplier_advance_unlink` — Снять связь аванса с поступлением

Право `money_post` (Проведение денег) · запись · разрушающая

Снимает связь платежа (payment_id) с поступлением (receipt_id): аванс снова открыт на эту сумму. Отвечает payment_id, receipt_id и amount_minor — снятую сумму в копейках. Связи нет — отказ not_linked.

Вход:
- `payment_id` — обязательное; integer > 0, ≤ 2147483647
- `receipt_id` — обязательное; integer > 0, ≤ 2147483647

## Себестоимость (`costs`)

### `cost_import_apply` — Записать импорт цен

Право `costs` (Себестоимость) · запись · разрушающая

Записывает себестоимость из таблицы: сопоставляет rows так же, как cost_import_check, и пишет только изменения; спорные строки (conflicts) и ненайденные (missing) не пишутся. source_file — имя файла или таблицы (до 200 знаков), уходит в журнал правок цен. Меняет прибыль всех периодов. Отвечает applied, unchanged, missing (строки без товара), conflicts и removed_product_ids (товары, исчезнувшие между сопоставлением и записью). Сначала покажите результат cost_import_check.

Вход:
- `rows` — обязательное; массив объектов (от 1 до 5000)
  - `barcode` — обязательное; string | null
  - `article` — обязательное; string | null
  - `cost_minor` — обязательное; integer ≥ 0, ≤ 9007199254740991
- `source_file` — обязательное; string длиной 1–200

### `cost_import_check` — Проверить импорт цен

Право `read` (Чтение) · чтение

Проверка импорта себестоимости без записи. rows — строки таблицы: barcode и article (оба поля обязательны; ключ, которого нет, — null или пустая строка, но хотя бы один должен быть задан) и cost_minor (целые копейки, не меньше 0); line в ответе — позиция строки во входе с 1. Отвечает changes (что изменится: товар, цена до и после, archived), unchanged_count, missing (строки, чей ключ не нашёл товара), conflicts (строка спорит с более ранней о цене того же товара — такой товар запись не тронет) и stock_delta_minor (на сколько изменится стоимость запасов по себестоимости, копейки). Запись — cost_import_apply.

Вход:
- `rows` — обязательное; массив объектов (от 1 до 5000)
  - `barcode` — обязательное; string | null
  - `article` — обязательное; string | null
  - `cost_minor` — обязательное; integer ≥ 0, ≤ 9007199254740991

### `product_set_cost` — Задать себестоимость товара

Право `costs` (Себестоимость) · запись · разрушающая

Задаёт себестоимость (cost_minor, целые копейки, не меньше 0) одного товара. Меняет прибыль всех периодов: она считается по текущей цене. Отвечает was_minor (цена до; null — не была задана) и became_minor. Неизвестный товар — отказ not_found.

Вход:
- `product_id` — обязательное; integer > 0, ≤ 2147483647
- `cost_minor` — обязательное; integer ≥ 0, ≤ 9007199254740991

### `stock_cost_revert` — Вернуть цену товара до поступления

Право `stock_post` (Проведение склада) · запись · разрушающая

Возвращает цену товара, записанную поступлением (document_id), к цене до него — по одному товару. Можно, только пока цену после документа никто не менял: иначе отказ cost_changed_since с текущей ценой. Отвечает was_minor (цена до документа), became_minor (цена документа) и remains_minor (цена после отката), в копейках. Что можно вернуть — costEvents в stock_document_get и cost_events в ответе stock_document_unpost.

Вход:
- `document_id` — обязательное; integer > 0, ≤ 2147483647
- `product_id` — обязательное; integer > 0, ≤ 2147483647
