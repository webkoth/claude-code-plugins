# Notice: Live Interview, Fully Transparent

Привет. Прежде чем начать — важное про режим этого собеседования.

Это **live-собеседование** с HR на звонке. Ты шаришь экран, идёт запись звонка. Этот плагин (`hr-eval`) логирует всё, что произойдёт в Claude Code сессии — и делает это **прозрачно для всех участников**:

**Что записывается:**
- Каждый твой prompt (текст, который ты отправляешь Claude)
- Каждый tool call, который Claude делает (Read, Edit, Bash, etc.) и его результат
- Все изменения файлов с diff
- Timestamps событий

**Куда сохраняется:**
- Локально, в `<cwd>/.hr-eval/sessions/<session-id>/log.jsonl`
- На твоей машине, никуда автоматически не уходит
- В конце сессии `/eval-report` соберёт пакет (отчёт + лог + task + profile), который ты передашь HR в звонке (drag-and-drop)

**Кто что видит и когда:**
- HR видит всё в реальном времени через screen share + запись звонка
- Финальный отчёт появляется одновременно у тебя на экране и у HR
- Полный лог сессии (`log.jsonl`) после звонка может смотреть team lead / lead dev при ревью найма
- Веса категорий и custom flags компании ты **уже видел** в `profile.yaml` на шаге `/eval-prepare` — никаких скрытых критериев

**Что НЕ записывается:**
- Содержимое других папок и проектов на твоей машине вне Claude контекста
- Системные данные, переменные окружения, секреты вне видимого Claude контекста
- Активность вне Claude Code (браузер, другие приложения)

**Что произойдёт в конце:**
Когда ты запустишь `/eval-report`:
1. Логирование остановится
2. LLM-анализатор прочитает лог и сгенерирует отчёт по 7 категориям мышления (Promptcraft, Critical Reception, Verification & Testing, Debugging Methodology, Architecture Steering, Environment & Tooling, Metacognition)
3. Веса из `profile.yaml` применятся прямо здесь — overall % fit и recommendation посчитаются inline
4. Отчёт появится у тебя на экране (HR увидит вместе с тобой через screen share)
5. Пакет соберётся в zip — ты перетянешь его в чат звонка / Telegram / email

**Зачем такая прозрачность:**
- Защищает обе стороны: ничего не скрывается, нечего оспаривать
- Ты уходишь со звонка с пониманием **куда расти**, даже если оффер не пройдёт
- Team lead / lead dev может потом перепроверить и оспорить или подтвердить оценку HR-а по логу
- Никаких "тайных критериев найма" — всё в `profile.yaml`

**Как тебе с этим работать:**
- Веди себя естественно. Оценивается **процесс мышления**, не количество шагов. Медленный кандидат, который рассуждает вслух и проверяет гипотезы, выглядит сильнее быстрого, который слепо принимает ответы AI.
- AI можно (и нужно) использовать. Скилл сделан в эпоху, где работа с AI-агентом — базовый навык. Вопрос не "пользуешься ли", а "как мыслишь когда пользуешься".
- Озвучивай гипотезы и сомнения. Это сигнал, не слабость.
- Если задача неясна — уточняй. Это плюс, не минус.

**Контроль:**
- `/eval-stop` — досрочно завершить сессию без генерации отчёта (если совсем что-то пошло не так)
- Лог `.hr-eval/sessions/<id>/log.jsonl` можно прочитать в любой момент — у тебя и у HR через screen share

Согласен начать? Напиши **"да"** или просто переходи к чтению `task.md`.
