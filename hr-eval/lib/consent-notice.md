# Notice: This Session Is Being Recorded

Привет. Прежде чем начать — важное.

Этот скилл (`hr-eval`) **прозрачно логирует** всё, что произойдёт в этой Claude Code сессии до момента, когда ты запустишь `/eval-report`:

**Что записывается:**
- Каждый твой prompt (текст, который ты отправляешь Claude)
- Каждый tool call, который Claude делает (Read, Edit, Bash, etc.) и его результат
- Все изменения файлов с diff
- Timestamps событий

**Куда сохраняется:**
- Локально, в текущей рабочей папке: `.hr-eval/sessions/<session-id>/log.jsonl`
- Никуда не отправляется автоматически — ни в облако, ни HR-у
- Ты сам решаешь отправлять ли финальный отчёт

**Что НЕ записывается:**
- Содержимое других папок и проектов на твоей машине
- Системные данные, переменные окружения, секреты вне видимого Claude контекста
- Активность вне Claude Code (браузер, другие приложения)

**Что произойдёт в конце:**
Когда ты запустишь `/eval-report`:
1. Логирование остановится
2. LLM-анализатор прочитает лог и сгенерирует отчёт по 7 категориям мышления (Promptcraft, Critical Reception, Verification & Testing, Debugging Methodology, Architecture Steering, Environment & Tooling, Metacognition)
3. Ты увидишь отчёт **до того**, как кто-либо ещё его увидит
4. Ты сам решаешь: отправить HR-у или нет

**Как тебе с этим работать:**
- Веди себя естественно. Скилл оценивает **процесс мышления**, не количество шагов. Медленный кандидат, который рассуждает вслух и проверяет гипотезы, выглядит сильнее быстрого, который слепо принимает ответы AI.
- AI можно (и нужно) использовать. Скилл сделан в эпоху, где работа с AI-агентом — базовый навык. Вопрос не "пользуешься ли", а "как мыслишь когда пользуешься".
- Озвучивай гипотезы и сомнения. Это сигнал, не слабость.
- Если задача неясна — уточняй. Это плюс, не минус.

**Что увидит HR (если ты отправишь отчёт):**
- Сводный scoring по 7 категориям
- Конкретные цитаты из твоих промптов и tool calls — как подтверждение каждого сигнала
- Список green flags (что у тебя получилось хорошо) и red flags (где были слабые места)
- Overall % fit (если HR приложит свой profile с весами для своей роли)

**Контроль:**
- `/eval-stop` — досрочно завершить сессию без генерации отчёта
- Лог `.hr-eval/sessions/<id>/log.jsonl` можно прочитать в любой момент

Согласен начать? Напиши **"да"** или просто переходи к чтению `task.md`.
